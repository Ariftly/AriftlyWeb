# Ariftly public research

This repository contains public research artifacts, synthetic fixtures and reproducible methodologies supporting articles published by [Ariftly](https://www.ariftly.io/insights).

## Research releases

- [Oracle-to-Snowflake migration validation fixtures](research/oracle-snowflake-validation/README.md) — version 0.1.0 test design supporting Ariftly's six-gate migration acceptance framework.

## Evidence boundary

Every release states whether its assets are a test design, an executed synthetic benchmark or observed production evidence. Test specifications must not be represented as measured results. Ariftly does not publish customer evidence without explicit authorization and provenance.
